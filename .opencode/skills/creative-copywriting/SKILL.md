# Creative Copywriting Skill —— 创意文案写作框架

## 何时加载

WBS 中出现"文案 / slogan / 标语 / 品牌主张 / 主题词"任务时加载。**必须在 DESIGN.md 完成后**才能调用（因为依赖 voice section）。

## 必产出物（写入 artifacts/<slug>/copywriting.md）

| 文案类型 | 数量 | 长度约束 | 用途 |
|---|---|---|---|
| **品牌 Slogan** | 3 候选 | ≤ 12 字（中文）/ ≤ 8 词（英文） | 主推广语 |
| **品牌主张** (Manifesto) | 1 段 | 80-150 字 | 关于页 / 校友信 |
| **Tagline** | 3 候选 | 6-15 字 | Logo 旁短词组 |
| **场景文案** | 3 条 | 30-60 字 | 招生页/活动 banner 等具体场景 |
| **核心关键词** | 8-12 个 | 单词或词组 | 后续 SEO / 内容创作的种子 |

## 写作框架

### 1. Slogan：3 个候选必须分属不同公式

| 公式 | 例子 |
|---|---|
| **动作公式**：动词 + 名词 | "做中学，创中悟" |
| **对仗公式**：A 与 B（强调融合） | "课堂在工位，导师即合伙人" |
| **疑问/反诘公式** | "为什么要等毕业才开始？" |

### 2. 品牌主张（Manifesto）结构

```
[现状描述：行业 / 用户的痛点 1-2 句]
[转折：我们看见了不一样的可能 1 句]
[承诺：我们做什么 / 不做什么 2-3 句]
[召唤：邀请受众加入 1 句]
```

### 3. Tagline 与 Logo 的关系

Tagline 是 Logo 旁的补充说明，**必须能脱离 Logo 单独成立**且**不重复品牌名**。

### 4. 场景文案

每条文案必须明确：受众 + 场景 + 行动召唤（CTA）。

## 调性约束（读取 DESIGN.md voice）

- 写完后**逐句对照** DESIGN.md voice 段的"禁用词"清单删除违规词
- 人称统一（不能时而"我们"时而"学院"）
- 中英文版本同时输出（即使品牌只服务中文受众，英文版也用于国际化预留）

## copywriting.md 输出模板

```markdown
# 创意文案 · [品牌中文名]

## 1. 品牌 Slogan（3 候选）
1. **首推**：[slogan-1]（公式：动作公式）
2. 备选 A：[slogan-2]（公式：对仗公式）
3. 备选 B：[slogan-3]（公式：疑问公式）

## 2. 品牌主张
> [80-150 字段落]

## 3. Tagline（3 候选）
- [tagline-1]
- [tagline-2]
- [tagline-3]

## 4. 场景文案
| 场景 | 受众 | 文案 | CTA |
|---|---|---|---|
| 招生页 hero | 18-25 岁开发者 | [文案] | "加入下一期" |
| 活动 banner | 一线工程师 | [文案] | "立即报名" |
| 校友信 | 已毕业学员 | [文案] | "回来分享" |

## 5. 核心关键词（8-12 个）
- 中文：[…]
- 英文：[…]

## 附：英文版（International Edition）
[Slogan / Manifesto / Tagline 英译]
```

## 反模式

- ❌ **空洞大词**：禁止"赋能 / 重塑 / 引领"等管理咨询黑话
- ❌ **押韵牺牲意义**：宁可不押韵也不要"快活/快乐/快速"这种凑韵
- ❌ **抄竞品**：写完后默念一遍，如果听起来像某个知名品牌就重写
- ❌ **跨调性混搭**：同一品牌的 3 个 slogan 候选必须保持调性一致（不能时而严肃时而调皮）

## 写完必做的自检（5 问）

1. 把品牌名遮住，slogan 还能识别出是哪个品类吗？（应该可以——这才有差异化）
2. 把 slogan 翻译成英文还成立吗？
3. 同事在电梯里听到这个 slogan，能记住吗？
4. 有没有出现 DESIGN.md voice 段的禁用词？
5. Tagline 与 Slogan 是否信息重叠？（应避免）
